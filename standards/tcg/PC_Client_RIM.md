# TCG PC Client Reference Integrity Manifest — 期待値の発行と評価

[TCG公式原典](https://www.trustedcomputinggroup.org/resources/documents/tcg-pc-client-reference-integrity-manifest-specification)。PC Client Firmware Profileの測定ログと対応するReference Integrity Manifest（RIM）の扱いを学ぶ。採用する原典の版とスキーマを検証側に固定する。

## 1. データ形式と信頼境界

| データ | 意味 |
|---|---|
| RIMの識別・版 | どのマニフェストを評価に使ったかを追跡 |
| プラットフォーム／ソフトウェアの識別 | 端末プロファイル、対象イメージ、版と照合 |
| 期待値とメタデータ | プラットフォームイベント等を評価する根拠。ハッシュ方式と計測対象も関連付け |
| 保護情報 | 配布元の真正性・完全性を確認するために採用した表現から取得 |

RIMの実際のタグ、構文、必須項目と署名形態には採用版の仕様とスキーマを用いる。上記は教材用の論理マッピング。TPMのQuoteのバイト列はEvidenceであり、期待値を表すRIMとは比較の両側になる。UEFI設定差が測定に影響する場合は共通の期待値一つに押し込まず、承認済みの組ごとに区別する。

## 2. 処理順・鍵・設定

1. Reference Value Providerが承認済みビルドと構成から期待値を発行する。
2. Verifierは配布元の信頼、版、プラットフォームIDを確認してインポートする。
3. Attesterから得た測定ログとQuoteを独立に検証する。
4. Verifierが参考値に一致するか評価し、使用したマニフェストを結果に記録する。
5. 更新時には新旧許容期間を管理し、許容終了時に旧版を拒否する。

発行者の署名鍵と端末AKを分離し、署名鍵のロールオーバーと期待値の失効を監査対象にする。［ラボ設定例］端末A/Bで同じ承認イメージを使い、各端末は別AKを持つ。配布元は共通化できる。実行時計測の参照値やSPDM測定値はデータの種類と発行主体を明示して個別に評価する。

## 3. OSSと検証

tpm2-toolsはログ／Quoteの検査、Keylimeの measured boot policy はポリシー評価の例。TCG RIMを直接取り込む場合は採用実装の対応形式を確認し、変換する場合は「原RIMの検証・意味を保った変換・変換結果の監査」を追加する。Keylime固有のポリシーファイルを標準RIMと呼ばない。

| ケース | 合格条件 |
|---|---|
| 正しい対象・版、署名、測定値 | 一致。使用したマニフェストIDを保存 |
| 正当な発行者だが別機種 | 期待値を流用せず不一致 |
| 旧版の有効期間が終了 | 測定値が一致しても旧ポリシーで許可しない |
| 配布が中断し未登録の構成になった | 評価不能を記録、通常ネットワークを許可しない |

設計演習では本体用とNIC用の期待値を別々に用意し、更新の担当者と対象を対応付ける。新旧2版を一時許容する場合、配布元の鍵失効と端末の許可期限をどの時計・どのデータで判断するか示す。

## 4. v1.1 rev.11のファイル関係を読む

[原典本文 §3](https://medias.cdn.trustedcomputinggroup.org/production/TCG_PC_Client_Reference_Integrity_Manifest_Specification_Version_1_1_Revision_11_pub_7cd780231f.pdf) ではBase RIMとSupport RIMを組として扱う。Base RIMの形式はISO/IEC 19770-2のSWIDに準拠し、NIST IR 8060のガイダンスに従う。Support RIMは本体に結び付いた追加資料として扱う。署名検証に加え、選択した本体と補助ファイル間の対応、同梱の構成、適用先を調べる。

| 観察 | 作業 | 証跡 |
|---|---|---|
| 発行 | どのベンダー・組織が、何を対象として発行したか読む | 発行者、対象ID、版 |
| 選択 | 同一機種に複数版がある場合、承認済み構成へ絞る | 選んだRIM Bundleと選択根拠 |
| 検証 | 真正性、補助ファイルの整合、TPM Quoteとイベントログの評価 | 構文・署名・測定の判定を分割 |
| 廃止 | 退役したイメージに対応する許可ポリシーから除く | 廃止日時、影響機種、運用承認 |
